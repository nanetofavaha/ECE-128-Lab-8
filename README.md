# ECE-128-Lab-8: Sequential and Combinational Multipliers

## Description

This lab focuses on designing and simulating sequential and combinational multipliers using Verilog. Both designs multiply two 4-bit binary numbers to produce an 8-bit product. The designs were tested using behavioral simulations in Vivado and implemented on the Basys 3 FPGA board

## Simulation

1. Open the project in Vivado
2. Add the Verilog source code and testbenches
3. Run the behavioral simulations
4. Use the waveforms to verify the multiplication results for each design

## FPGA Implementation

1. Add the XDC constraints file to the project
2. Assign the switches, push buttons, clock, and LED pins
3. Run synthesis and implementation
4. Generate the bitstream
5. Connect and program the Basys 3 FPGA board
6. Set the input values using the switches and observe the multiplication results on the LEDs
